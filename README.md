## 使用约定

1. **每周日固定提交**（提交锚点，比"每两周"更稳）：`git add .` → `git commit -m "..."` → `git push`，提交信息写清周次和做了什么（例：`第2周：HTML文本与列表标签练习`）。当周确实没学就提交一条"本周暂停（原因）"——如实记录本身就是轨迹。
2. **进度如实记录**：没学的标"未开始"，不提前打勾——答辩时每个勾都可能被追问。
3. **资源链接失效时**：记录失效日期并就近替换同类资源，不删除原条目——这本身就是真实的"资料整理"轨迹。
